## Граница текущей версии

Динамическая логика проверена на Windows x64 с MinGW-w64. Независимая сборка и
тестирование MSVC предусмотрены в `.github/workflows/ci.yml`, но для
формального повышения версии с `1.0.0-rc1` до `1.0.0` этот job должен пройти
на итоговой ревизии.

Локальный libFuzzer target успешно собирается LLVM 21. Полная ограниченная
кампания выполняется Linux CI; локальный macOS-прогон оказался существенно
медленнее установленного временного бюджета. Дополнительно выполнено 1000
детерминированных мутаций без сбоев и некорректных отчётов.

## Статус передачи

Пакет `*-windows-x64.zip` готов для функциональной передачи заказчику.
Пакеты `*-source.zip` и `*-evidence.zip` предназначены соответственно для
разработчика и для аудита результатов. Контрольные суммы находятся в
`SHA256SUMS.txt`.
